    How to play

    Drop

    Aim along the top of the crate, release to drop the current fruit. Matching tiers merge into the next tier and score points (tier² × 5).

    Warning line

    If settled fruit stays above the glowing line for the grace period, the run overflows and ends.

    Controls

    Drag / aim slider, ←→ aim, Space drop, U undo (practice), H hint, P pause, R restart.

    Modes

    Learn: guided tutorial. Journey: 40 staged goals. Daily: one ranked run per UTC day. Practice: relaxed, with undo. Challenge: preset rule variants.
